# Operator v1 — scope frozen 26 September 2026

v1 is what is in the app today. **No new features go into v1.** A new idea goes
on the v1.1 list at the bottom and waits. What is left before launch is making
it sellable, not making it bigger (plan-30k.md, rule 5: traffic before features).

## In v1

- An agent that drives this PC: its own hidden desktop, its own browser, your
  screen when you say "my", PowerShell, files
- Agents with a name, face, persona and memory; workspaces; the start screen
- Helpers: up to four web jobs at the same time
- Your turn: it asks, waits and carries on — codes from Gmail, captchas handed to you
- Reminders and routines it can set, list and cancel itself
- The check at the end of every task, the audit log, rehearse (dry run), undo on deletes
- Code mode; voice mode; a model dial for each model
- Claude on the customer's own Anthropic API key, or NVIDIA NIM models

Skipped on purpose: licence keys and a trial mode.
