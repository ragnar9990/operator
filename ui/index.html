Which computer Operator uses

Run start-operator-node.cmd on the other machine; it prints an address and token. This link uses your network, so keep both machines on the same one (or on Tailscale).

Which brains Operator can use
Claude On your Claude subscription — nothing to set up
NVIDIA NIM Not connected

One key, every other vendor's models: Meta's Llama, Google's Gemma, Mistral, DeepSeek, Qwen, Microsoft's Phi, IBM Granite, Moonshot Kimi, Z.ai GLM, OpenAI's open weights and NVIDIA's own Nemotron family — all through NVIDIA's hosted endpoint.

Get one free at build.nvidia.com — sign in, open any model and click Get API Key. Paste the key or the whole Bearer … line, either works. It is stored only on this computer.

NVIDIA lists every model it has ever published, but only serves some of them to any given key. This tries each one and takes the dead ones out of the picker. It takes a minute or two.

Connect your accounts so the agents can use them
Phone Off

Your phone sends Operator the codes it receives, so it can finish signing you in without waiting on you. Set up a shortcut on the phone to POST to the address below — see PHONE.md for how, on iPhone and Android.

Only reachable on your own network, and only with that token. Texts are held in memory for ten minutes, used once, and never written to disk. A new token unpairs any phone that had the old one.

@ Agents can read and send mail

Let your agents read and send your mail. Sign in with Google for Gmail, or connect any other mailbox with an app password.

One-time setup. In your Google Cloud project, enable the Gmail API and create an OAuth client ID of type Desktop app, then paste it here. Stored only on this computer.

Check the work

Before a task is allowed to tell you it is done, a second, cheaper model looks at what you asked for, every action it took and the screen as it is now, and says whether the goal was actually met. If it was not, the agent is sent back to finish the job — once. It adds about eight seconds to the end of a task and costs around a cent.

Audit — every action, on the record

Written as it happens and never edited afterwards. Passwords, card numbers and tokens are replaced with a fingerprint before anything reaches the disk, so this file is safe to hand to someone else.
